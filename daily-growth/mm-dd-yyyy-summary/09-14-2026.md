# 09-14-2026 Summary

## Style system and Home

- Implemented the [style-system roadmap](../roadmaps/style-system-revamp.md)
  with a restrained Zed-style direction: compact controls, quiet separators,
  consistent spacing, and clearer typography. Kept the existing GPUI 0.2.2
  dependency; no additional styling library or dependency changes were needed.
- Added a pure Rust `UiTheme` with semantic colors, explicit light/dark modes,
  typography roles, spacing, control heights, and radii. Replaced
  `WorkspacePalette` and duplicated editor chrome colors.
- Added shared GPUI buttons, icon buttons, checkboxes, panels, section headings,
  settings rows, and interaction helpers. Controls share hover, pressed,
  selected, disabled, and visible focus states with pointer and Enter/Space
  activation. Fixed nested-control event handling and tab/content focus behavior.
- Separated native system-font chrome from bundled Atkinson Hyperlegible reading
  text. Editor code fonts, syntax highlighting, terminal ANSI colors, cursor
  effects, and text metrics retain their existing ownership.
- Rebuilt Home around direct course selection and a single Continue lesson
  action beside a prominent, immediately editable notepad. Open project and
  recent projects are secondary. Narrow panes place writing after compact course
  entry and before the full catalog/projects, using actual pane widths.
- Refined note titles, writing placeholders, recent-note navigation, New note
  persistence, and Tab/Shift-Tab traversal while preserving automatic saving,
  shared notes, error reporting, and code-editor indentation behavior.
- Migrated Courses, Settings/Appearances, sidebar, tabs, footer, pane chrome,
  command palette, editor headers, status bars, markdown controls, and editor
  overlays to the shared style system. Cached course logos outside render work.
- Added a debug-only gallery of the production controls and theme variants,
  enabled with `LLNZY_STYLE_GALLERY=1`; an optional local image can be supplied
  with `LLNZY_STYLE_GALLERY_IMAGE`.

## Appearance and background images

- Made UI mode explicit and persistent. Resolution prefers saved mode, then
  configured mode, a recognized preset, and finally the legacy background-color
  heuristic. Old and unknown preferences remain recoverable.
- Preserved background image selection, display mode, fit, brightness/intensity,
  and compatible effect settings across theme changes and restarts. None can
  remember an image for later; Clear removes it, including config-file fallback.
- Shared image-backed surface tints across Home, Courses, and Settings while
  keeping local writing surfaces readable. Retained existing image/blur handling.
- Propagated appearance updates to existing workspace windows and shared notes;
  new windows resolve the saved preferences.
- Included the pending Light Mode work: neutral chrome and terminal rendering
  that respects a light background instead of forcing the dark terminal fill.

## Evening: Settings Appearances, editor themes, JetBrains Mono

- Renamed the Settings sub-tab Home to Appearances (default page); Courses is
  the other sub-tab and keeps word wrap and markdown preview controls.
- Added an EDITOR section to Appearances with editor themes grouped Dark
  (One Dark, Dracula, Nord) and Light (One Light, Solarized Light, GitHub
  Light), plus the editor and sidebar font size rows moved from Courses.
- Editor themes now carry editor background, foreground, cursor, and selection
  as well as the syntax palette (`Config.editor_colors`). With no theme chosen
  the editor still follows the terminal scheme. The saved preference key is
  unchanged so earlier selections keep resolving. The Home notepad keeps its
  reading colors.
- Registered the bundled JetBrains Mono faces (regular, bold, italic, bold
  italic) at startup. The code editor defaults to JetBrains Mono via the new
  `[editor].font_family` key and no longer inherits the terminal font.
- Fixed caret drift with JetBrains Mono: ligatures (`::`, `->`) shaped several
  columns into one glyph and pushed later highlight chunks off the column
  grid. The editor now disables `calt` for rendering and measurement, and pins
  each chunk to its exact column width. Verified visually by Luke.
- Gate: fmt, clippy `-D warnings`, and `cargo test --all-targets
  --all-features` green (622 unit tests). Docs updated: README, architecture,
  configuration, manual smoke tests. Not yet committed; the working tree also
  still holds the effects/scrollback removal from earlier today.
- Added an Error Log sub-tab to Settings (Appearances, Courses, Error Log).
  The log with its filters, Copy All, and Clear moved there and is always
  open; the Workspace & Diagnostics block left Appearances.
- Build hiccup: cargo failed to hard-link older build-script binaries under
  `target/debug/build` ("Operation not permitted") while fresh outputs linked
  fine. Refreshing each binary in place with a copy of itself and rebuilding
  (about 12 minutes) cleared it. Gate green afterwards (624 unit tests).
- Moved word wrap and the markdown preview controls from Courses into
  Appearances → Editor. Courses is intentionally empty for now.
- Replaced the Settings theme cards with two clickable pixel-art thumbnails,
  Light Mode and Dark Mode: a video-game style monitor showing the app in
  that mode (title bar, sidebar, editor, terminal, status bar, scanlines,
  glare), painted by `scripts/theme_thumbnails.py`, box-downsampled to a
  66 x 42 grid, quantized to 72 colors, and scaled up nearest-neighbour. Bundled as
  `assets/theme-light.png` and `assets/theme-dark.png`, decoded once per
  process. The Themes heading and swatch strip are gone.
- Neutralized the dark chrome palette. Panel, editor, and reading surfaces
  were blue-leaning grays (#1b1b22, #191920) and read as a second color
  inside tabs; they now sit on the same #242424 as the terminal, with
  neutral borders, hover, pressed, and selection grays to match.
- Home now splits courses and the notepad into two separate bordered
  containers in columns with a gap, instead of one panel divided by a rule.
  Narrow panes stack the same containers.
- Fixed the notepad caret sitting past the end of the text. The caret is a
  flex sibling after the preceding text box; pinning that box to column
  count times the average advance (added with the ligature fix) overshot for
  the proportional reading face. Boxes take their shaped width again;
  ligatures stay off, which was the actual cause of the code-editor drift.
