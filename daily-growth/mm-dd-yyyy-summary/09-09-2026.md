# 09-09-2026 Summary

## Breadcrumbs

**macOS display-change crash investigation**
- Investigated the report that the installed, DMG-packaged app closes when
  connecting HDMI or changing displays. Read the architecture map, startup
  and window lifecycle code, packaging script, effects pipeline, and GPUI's
  macOS display-link and rendering implementations.
- Existing runtime logs contain display-link creation failures (`-6661`).
  The saved crash log only retained a panic during destructor cleanup, so it
  did not establish the original failure or conclusively identify this crash.
- Found that LLNZY explicitly enabled GPUI 0.2.2's `macos-blade` feature.
  Blade 0.7.1 unwraps `nextDrawable()`, which can panic when no drawable is
  available. An upstream report describes crashes when moving windows
  between displays with this renderer:
  [GPUI issue #27767](https://github.com/zed-industries/zed/issues/27767).
  This is a strong match, pending reproduction with the user's HDMI setup.

**Renderer and diagnostics changes**
- Switched GPUI to its native Metal renderer, which skips a frame when a
  drawable is unavailable. Enabled `runtime_shaders` so the app can build
  with Command Line Tools without the offline Metal compiler. Shader source
  ships in the binary and compiles locally at launch.
- Kept dependency versions unchanged and updated Cargo.lock for the feature
  change. The existing NV12 shader-background format is supported by native
  Metal; updated effects comments to describe the selected renderer.
- Changed the production panic hook to append timestamped crash entries,
  process/version context, and backtraces. A later cleanup panic can no
  longer overwrite the original cause. Added a regression test for this.
- Documented the renderer choice in `docs/development.md` and added HDMI,
  scaling, mirroring, fullscreen, Spaces, and sleep/wake checks to
  `docs/manual-smoke-tests.md`.

## Shader patterns removed from Appearances

**Request**

Work on the Settings tab's Appearances section, starting by removing the shader
patterns. They are not wanted anymore.

**What came out**

- The Background row is now `None` / `Image`. The `Smoke`, `Fire`, `Aurora`, and
  `Trees` buttons are gone, along with the palette presets, the intensity row,
  the active-color strip, and the live preview.
- `src/effects/` deleted in full: `host.rs`, `element.rs`, and six `.wgsl`
  files — the wgpu → CVPixelBuffer → `paint_surface` bridge, and the M1–M3
  work behind it.
- `src/gpui_workspace/appearances/shader_palettes.rs` (320 lines) deleted, plus
  `palette_band` in `widgets.rs`.
- `workspace_shader_effect_layer`, `default_palette_for`, and
  `terminal_uses_shader_effect` removed from `gpui_terminal.rs`, with their
  three mount sites in `panes.rs`.
- macOS dependencies `wgpu`, `wgpu-hal`, `naga`, `core-video`,
  `core-foundation`, `metal`, and `pollster` removed from `Cargo.toml` — 262
  lines out of `Cargo.lock`. The `naga` / `metal` / `pollster` entries that
  remain are GPUI's own transitive deps.
- Config fields `background_color`, `background_color2`, `background_color3`,
  and `background_speed` removed from the model, the TOML schema, the
  saved-theme format, and preferences. `BackgroundImageFit::shader_mode` and
  `AppPaths::shaders_dir` went with them.

**Decisions worth keeping**

- `background_intensity` stayed. It also drives the background-image dim
  (`1 - intensity`) and the text-shimmer alpha, and its only control lived in
  the shader row — deleting that row outright would have stranded whatever
  value a user had persisted. It is now an **Image Brightness** row under the
  image controls, which is where it actually applies.
- Legacy state degrades instead of breaking: `config::normalize_background_mode`
  maps anything that is not `image` — including `smoke`, `fire`, `aurora`,
  `trees`, and `rain` — to `none`, applied both when reading `config.toml` and
  when loading a saved theme. Two tests cover it.
- Particles lost their palette override and now cycle a fixed three-color
  constant.
- Post Effects (Bloom / CRT / Particles) and Text Effects (Glow / Trail /
  Text Anim) are untouched. They are CPU-drawn quads, not shaders.

  and `cargo test --all-features` all pass. 653 tests, two added.
